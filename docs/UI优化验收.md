# UI 与交互优化验收

日期：2026-10-18。

## 已落地

- 设置：侧栏分类、可滚动详情、系统浅深色、统一的标题与卡片间距、左侧说明和右侧开关；保存窗口位置。
- 图片美化：自适应外观、背景色板、连续留白与圆角滑块、独立导出区；支持全部模型外框和 3:4 画幅，重开后显示当前参数。
- 预览与交付：防抖、参数副本、串行渲染、过期请求丢弃；等待最新预览后导出。后台编码、原子写盘、失败留在窗口并提示。
- 快捷操作：Enter 复制并完成、⌘S 保存、⌥P 贴图、Esc 关闭；补充标准编辑菜单。
- 截图 HUD：原生材质与 SF Symbols，统一选中、悬停、按下与禁用状态；提示与动画尊重减少动态效果。
- 缩略图：不抢焦点、悬停暂停自动关闭、防止旧动画隐藏新的结果；无永久文件时禁用访达操作。
- 录屏：移除未接入的暂停控件，显示本轮声音设置；准备和保存期间防止重入，30/60 FPS 偏好实际传入录制参数，保存期间冻结计时并禁用结束按钮。
- 通知：避免“已保存”误称“已复制”或无条件宣称含系统声音。
