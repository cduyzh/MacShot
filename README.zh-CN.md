# SnapScreen（极速截屏）

原生 macOS 截图、滚动长截图与带系统声音录屏工具。

**SnapScreen** 是一款现代、轻量的原生菜单栏应用，覆盖 macOS 上的完整截图工作流：区域截图与标注、滚动长截图、屏幕贴图、图片美化工作室，以及带系统声音的屏幕录制。应用使用 Swift 6、AppKit、SwiftUI 与 ScreenCaptureKit 构建，零第三方闭源依赖。

## 功能特性

### 区域截图

- **智能窗口吸附** — 按 `⌃A`（Control + A）或点击菜单栏图标开始截图。鼠标悬停自动高亮识别窗口边界（基于 `CGWindowListCopyWindowInfo`），单击直接选中该窗口，也可自由拖拽任意矩形。
- **取色放大镜** — 选区建立前，放大镜跟随鼠标移动，提供 4x 视网膜像素网格、中心准星、RGB Hex 十六进制色值（如 `#3B82F6`）以及精确坐标尺寸。
- **矢量标注工具栏** — 矩形（`1`）/ 圆形（`2`）/ 箭头（`3`）/ 直线 / 马赛克与高斯模糊（`6`）/ 文本输入框（`7`，支持背景气泡与自适应大小）/ 自增序号徽章（`8`，适合分步说明），以及预设调色盘。几何标注使用固定线宽，画面干净利落。
- **悬浮功能提示** — 鼠标在工具栏按钮上短暂停留，即展示功能名称与快捷键徽章（如 `矩形 [1]`、`美化 [E]`、`完成并复制 [Enter]`）；提示在按钮间平滑跟随过渡，鼠标点击完全穿透，并尊重系统"减少动态效果"设置。
- **极速交互** — `Enter` 或双击立即完成并复制到剪贴板；`Cmd + S` 保存至下载目录（附系统通知可直接"在访达中显示"）；`Cmd + Z` 撤销上一条标注；`Esc` 或选区外右键取消退出。

### 滚动长截图

- **随处开始** — 按 `⌥S`（Option + S），或在截图选区工具栏点击"长截图"。
- **实时捕获** — 使用 ScreenCaptureKit 异步读取选区画面，控制面板与边框从捕获内容中排除；捕获与拼接不阻塞主线程。
- **滚动模式** — 支持触控板 / 滚轮手动滚动。开启辅助功能权限后，可点击"向上捕获""向下捕获"从当前位置向两侧补全；回看已捕获的内容不会重复拼接。
- **接缝恢复** — 短暂配准失败自动重试；持续失配时保留成功画面参照，点击"帮我接回"小步寻找可拼接位置，找到后再选择方向。未开启辅助功能权限时，按提示小步返回，对齐后自动恢复手动捕获。
- **可靠拼接** — 基于多行、多列的 RGB 特征进行纵向对齐并保留匹配置信门槛，不会将失配误判为触底。固定页眉页尾在有足够证据时只保留一次；窗口移动、尺寸变化或无法可靠对齐时给出明确提示，而非生成破图。
- **内存可控、干净收尾** — 仅保留首屏、增量条带与少量工作帧，约 40 MP 安全上限。结束时只合成一次，后台原子写入带唯一文件名的 PNG，按偏好复制剪贴板，保存成功后才发送通知。取消则丢弃本轮数据。

### 原生系统声音录屏

- **一键开录** — 按 `⌃[`（Control + `[`）开始，再次按下停止。
- **免装声卡驱动** — 直接集成 ScreenCaptureKit（`capturesAudio = true`），以 48kHz 立体声 PCM 捕获 Mac 扬声器播放的全部系统声音，无需安装 Soundflower / BlackHole 等虚拟声卡驱动。
- **高质量编码** — 基于 `AVAssetWriter` 输出 60 FPS H.264 视频与 AAC 音频。
- **悬浮控制面板** — 实时录制计时器、状态红点、真实系统声音状态与结束按钮；保存期间冻结计时并显示"正在保存"。暂不提供暂停功能。
- **完成通知** — 录制完成自动保存至 `~/Downloads`，自动复制文件路径并推送通知。

### 屏幕贴图

- **置顶悬浮** — 按 `⌥P`（Option + P）或在截图工具栏点击"贴图"，将截图钉在系统最高层级窗口之上，不被任何窗口遮挡。
- **任意拖动缩放** — 随意移动贴图位置，滚轮即可放大缩小。
- **右键菜单** — 复制、另存为、调整透明度（100%、80%、50%、30%）；双击直接关闭。

### 图片美化工作室与样机外框

- **三种进入方式** — 截图标注时按 `E`（或点击美化按钮）；截屏后点击右下角悬浮缩略图上的美化按钮；或随时按 `⌥E`（Option + E）从剪贴板载入图片 / 选取本地文件。
- **样机外框** — macOS 浅色视窗（原生 Retina 交通灯按钮与浅色机身金属光泽）；macOS 深色视窗（暗色标题栏与高对比度交通灯）；现代浏览器外框（Safari / Chrome 风格极简地址栏，支持安全小锁图标、仿真域名及前进后退刷新按键）；或无框纯净模式只保留画芯。
- **背景与智能毛玻璃** — 智能高斯毛玻璃对截图本身做超分辨率缩放与多阶模糊，背景色调与主体完美融合；多款精选渐变壁纸（晨曦暮光、北极微光、薄暮暖霞、深海幽蓝、暗黑钛金）；优雅纯色背景；以及支持透明 PNG 导出的棋盘格背景。
- **构图调节** — 外边距留白 0～100px、视窗圆角 0～40px、柔和 / 深邃两级弥散阴影，全部平滑无损调节。
- **社交平台画幅** — 一键匹配自适应 Auto、1:1 正方形、4:3 经典、16:9 横屏、9:16 移动竖屏或 3:4 图文画幅。
- **极速分发** — `Enter` 复制合成大图至剪贴板，`Cmd + S` 保存高清晰度 PNG，`⌥P` 直接将成品钉在桌面上浮动比对。

### 原生应用体验

- **菜单栏控制** — 左键菜单栏图标直接截图；右键打开状态面板，集中展示常用操作、快捷键与实时权限、录制状态；维护操作收在"更多"中。
- **原生设置** — 侧栏分类、可滚动的设置窗口，支持窗口缩放与位置记忆。
- **外观自适应工作室** — 美化工作室跟随系统浅色 / 深色外观，背景色板、留白、圆角与画幅实时预览；快速调整会合并渲染请求，导出等待最新预览，避免复制过期结果。
- **贴心的缩略图** — 截屏后的悬浮缩略图不抢焦点，鼠标悬停暂停自动关闭，移出后至少保留 2 秒。
- **检查更新** — 可从状态栏菜单、应用主菜单或设置面板一键检查更新；支持 GitHub Releases 或自建更新源（私有仓库可配置 PAT 令牌授权）；发现新版本时以原生弹窗展示更新日志并直接下载。
- **更新记录查看** — 菜单"更新记录…"与设置"关于与更新"均显示实际安装版本与构建时间；新版首次启动展示本次更新记录，之后可随时从菜单重新打开。

## 快捷键

| 功能 | 快捷键 | 备注 |
| :--- | :--- | :--- |
| 区域截图 | `⌃A`（Control + A） | 窗口吸附 / 自由选区 |
| 滚动长截图 | `⌥S`（Option + S） | 自动 / 手动滚动拼接 |
| 图片美化工作室 | `⌥E`（Option + E） | 从剪贴板或本地文件载入 |

| 屏幕贴图 | `⌥P`（Option + P） | 置顶悬浮图片 |

| 保存文件 | `Cmd + S` | 保存至默认目录 |

## 下载与安装

1. 前往 [GitHub Releases](https://github.com/cduyzh/SnapScreen/releases) 下载最新 DMG。
2. 打开 DMG，将应用拖入 **应用程序（Applications）** 文件夹。
3. 启动应用。首次使用请授予 **屏幕录制** 权限（系统设置 → 隐私与安全性）；长截图自动滚动需 **辅助功能** 权限；如需录制人声可授予 **麦克风** 权限。

## 从源码构建

需要 macOS 14+，以及 Xcode 或 Command Line Tools（Swift 5.9+）。

```bash
git clone https://github.com/cduyzh/SnapScreen.git
cd SnapScreen
./build_app.sh
```

## 隐私

你的所有截图与录屏都保留在本机。复制操作只写入剪贴板（以及可选的临时文件）；只有在你主动保存时才会写入永久文件。唯一的网络访问是可选的更新检查（指向 GitHub Releases 或你配置的更新源）——无分析统计、无遥测、零第三方闭源依赖。应用只申请功能所需的权限：屏幕录制（截图 / 长截图 / 录屏）、辅助功能（自动滚动），以及可选的麦克风（录制人声）。
